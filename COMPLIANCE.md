# Compliance & Attribution

This pack is an original-content rewrite. The pipeline skills express the
workflow in this pack's own words; no prose is copied verbatim from any other
project.

## Origin

The sriflow workflow was originally inspired by patterns from these open-source
projects (all MIT licensed):

- gstack (Garry Tan, MIT)
- ECC / effective-coding-contexts (Affaan Mustafa, MIT)
- ruflo (ruvnet, MIT)
- agentskills (Agntcy)

Their ideas (forcing questions, review lenses, error resolvers, memory
backends, token budgets, phased delivery) were absorbed as *concepts* and
re-expressed in original prose for this pack. No MIT copyright notice is
required for original expression; this note records provenance for
transparency.
